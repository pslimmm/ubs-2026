**Architecture:** Keep the existing score-model and single-route structure. - Treat `legal_actions`, `min_raise_to`, and `max_raise_to` as authoritative.
- Never re-raise opponent aggression.
- Ordinary calls may add at most 10 big blinds; only a non-losing hand may exceed that ceiling.
- Keep requests deterministic, local, and below five seconds.
- Modify only `routes/showdown.py`, `tests/test_showdown.py`, and Superpowers documentation.
- Do not add dependencies, Phase 3 behavior, or unrelated refactoring.

```python
def _future_blind_cost(data: dict) -> float:
    remaining = max(data.get("total_hands", 0) - data.get("hand_number", 0), 0)
    seat, button = data.get("your_seat"), data.get("button_seat")
    small, big = data.get("small_blind", 1), data.get("big_blind", 2)
    if not all(isinstance(value, (int, float)) for value in (seat, button, small, big)):
        return big * remaining if isinstance(big, (int, float)) else 2 * remaining
    return sum(
        small if seat == (button + offset) % 2 else big
        for offset in range(1, remaining + 1)
    )
```

```python
OPEN_EQUITY = 0.60
CALL_EQUITY = 0.80
```

`_opponent_reraised` must scan only the current round, normalize seats with `str`, remember whether we previously bet or raised, and return true only for a later opponent raise. `_opponent_checked` returns true for an opponent check in the current round.

`_wager_amount` returns a clamped target:

```python
target = (
    round(2.5 * big_blind)
    if data.get("round") == "pre_reveal"
    else round(2 * pot / 3)
)
```

Apply `_move` decisions in this order:

1. Secured-target protection.
2. Opponent re-raise: call only at `NUT_EQUITY`, otherwise fold.
3. Unopened pre-reveal raise at `OPEN_EQUITY` using `_wager_amount`.
4. Facing a wager: call at `NUT_EQUITY`, or at `CALL_EQUITY` when the wager is at most 10 big blinds; otherwise fold. Treat `to_call > big_blind` as a wager even if history is absent.
5. After an opponent check, bet the legal minimum at `STEAL_EQUITY`.
6. Other free post-reveal actions bet two-thirds pot at `OPEN_EQUITY`.
7. Preserve legal check/fold/call and bounded bet/raise fallbacks.
